Getting Started with Orderly Chaos

Orderly Chaos is a high-performance limit order book implementation with price-time priority matching, designed for financial market data streaming. This guide will help you get up and running quickly.

Table of Contents

  • Installation
  • Quick Start
  • Python Guide
  • C++ Guide
  • C API Guide
  • Development Setup

Installation

Python (from PyPI)

pip install orderly-chaos

Python (from source)

git clone https://github.com/Meetmendapara09/Orderly-Chaos.git
cd Orderly-Chaos
scons
pip install -e .

Build Requirements

Orderly Chaos requires the following dependencies:

  • C++ Compiler: GCC 7+ (g++ with C++17 support)
  • Python: 3.5+ (for Python bindings)
  • SCons: Build system (pip install scons)
  • On Windows: Visual Studio 17.0 tools or MinGW-w64

Quick Start

Python Example

from orderly_chaos import LimitOrderBook

# Create a new order book
book = LimitOrderBook()

# Place limit orders
book.limit_sell(order_id=1, quantity=100, price=102.50)
book.limit_buy(order_id=2, quantity=50, price=102.40)

# Market orders
book.market_buy(order_id=3, quantity=75)

# Check state
print(f"Best Ask: ${book.best_sell()}")
print(f"Best Bid: ${book.best_buy()}")
print(f"Total Volume: {book.volume()}")
print(f"Order Count: {book.count()}")

# Cancel an order
book.cancel(1)

C++ Example

#include "limit_order_book.hpp"
#include <iostream>

int main() {
    LOB::LimitOrderBook book;

    // Place limit orders
    book.limit_sell(1, 100, 10250);  // order_id=1, qty=100, price=102.50
    book.limit_buy(2, 50, 10240);    // order_id=2, qty=50, price=102.40

    // Market orders
    book.market_buy(3, 75);          // order_id=3, qty=75

    // Query state
    std::cout << "Best Ask: " << book.best_sell() << std::endl;
    std::cout << "Best Bid: " << book.best_buy() << std::endl;
    std::cout << "Total Volume: " << book.volume() << std::endl;

    return 0;
}

Python Guide

Creating a Limit Order Book

from orderly_chaos import LimitOrderBook

book = LimitOrderBook()

Placing Orders

There are several methods for placing orders:

Limit Orders

# Place a sell limit order
book.limit_sell(order_id=1, quantity=100, price=102.50)

# Place a buy limit order
book.limit_buy(order_id=2, quantity=50, price=102.40)

# Place using generic limit method
# side=True for buy, side=False for sell
book.limit(side=True, order_id=3, quantity=75, price=102.30)

Market Orders

# Execute a market buy (matches against sell side)
book.market_buy(order_id=4, quantity=100)

# Execute a market sell (matches against buy side)
book.market_sell(order_id=5, quantity=50)

# Generic market method
book.market(side=True, order_id=6, quantity=30)

Querying the Book

# Best prices
book.best_sell()     # best ask price (sell side)
book.best_buy()      # best bid price (buy side)
book.best(side=True) # best price for given side

# Volumes
book.volume()           # total volume across both sides
book.volume_sell()      # total sell-side volume
book.volume_buy()       # total buy-side volume
book.volume(price)      # volume at a specific price level

# Counts
book.count()            # total orders in book
book.count_sell()       # orders on sell side
book.count_buy()        # orders on buy side
book.count_at(price)    # orders at a specific price

# Order existence
book.has(order_id=1)    # check if order exists

# Cancel orders
book.cancel(order_id=1)

# Clear book
book.clear()

C++ Guide

Include and Link

#include "limit_order_book.hpp"

// Link against lib_orderly_chaos.so (Linux/Mac) 
// or lib_orderly_chaos.dll (Windows)

C++ API Example

#include "limit_order_book.hpp"
#include <iostream>

using namespace LOB;

int main() {
    LimitOrderBook book;

    // Place limit orders
    book.limit_sell(1, 100, 10250);
    book.limit_buy(2, 50, 10240);

    // Market orders
    book.market_sell(3, 25);
    book.market_buy(4, 10);

    // Query
    std::cout << "Volume: " << book.volume() << std::endl;
    std::cout << "Count: " << book.count() << std::endl;

    // Cancel
    book.cancel(1);

    return 0;
}

C API Guide

The C API provides a simple interface for other languages to interact with the engine.

#include "lib_lob.hpp"

int main() {
    // Create book
    void* book = new_();

    // Place orders
    limit_sell(book, 1, 100, 10250);
    limit_buy(book, 2, 50, 10240);

    // Market orders
    market_buy(book, 3, 25);

    // Query
    Price best_ask = best_sell(book);
    Price best_bid = best_buy(book);
    Volume total_vol = volume(book);

    // Cancel and cleanup
    cancel(book, 1);
    delete_(book);

    return 0;
}
