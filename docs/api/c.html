C API

A stable, C-compatible interface declared in orderly_chaos/orderly_chaos.h, for C programs and for any language with a C FFI.

Conventions

  • Every function that changes the book returns an oc_status; OC_OK (0) means success. A failed call never modifies the book.
  • Query functions return 0 when the book pointer is NULL, the side is invalid, or there is no data (such as the best price of an empty side).
  • Prices are integer ticks and 0 is reserved. Output pointers documented as optional may be NULL.
  • All symbols use the oc_ prefix. A book is not thread-safe.

Example

#include <stdio.h>
#include <orderly_chaos/orderly_chaos.h>

static void on_trade(const oc_trade* t, void* user_data) {
    (void)user_data;
    printf("%llu traded with %llu: %u @ %llu\n", (unsigned long long)t->taker_id,
           (unsigned long long)t->maker_id, t->quantity, (unsigned long long)t->price);
}

int main(void) {
    uint32_t filled = 0;
    oc_book* book = oc_book_new();
    if (book == NULL) return 1;
    oc_book_set_trade_callback(book, on_trade, NULL);

    oc_book_limit(book, OC_SIDE_SELL, 1, 100, 10050, NULL);
    oc_book_limit(book, OC_SIDE_BUY, 2, 40, 10050, &filled);   /* filled == 40 */

    oc_status status = oc_book_cancel(book, 99);
    if (status != OC_OK) printf("cancel failed: %s\n", oc_status_string(status));

    oc_book_free(book);
    return 0;
}

Types

TypeDefinition
oc_bookOpaque handle; create with oc_book_new, destroy with oc_book_free
oc_sideint32_t: OC_SIDE_SELL (0) or OC_SIDE_BUY (1)
oc_statusint32_t status code (see below)
oc_order{ uint64_t order_id; uint64_t price; uint32_t quantity; oc_side side; } (24 bytes)
oc_trade{ uint64_t taker_id, maker_id, price; uint32_t quantity, maker_remaining; oc_side taker_side; } (40 bytes)
oc_level{ uint64_t price, volume, count; } (24 bytes)
oc_trade_callbackvoid (*)(const oc_trade* trade, void* user_data)

The struct layouts and sizes are part of the ABI and are checked by the test suite.

Status codes

CodeValueMeaning
OC_OK0Success
OC_ERR_DUPLICATE_ORDER_ID1A limit order used an ID that is already resting
OC_ERR_UNKNOWN_ORDER_ID2No resting order has the ID
OC_ERR_INVALID_QUANTITY3Quantity is 0 or exceeds the open quantity
OC_ERR_INVALID_PRICE4Limit price is 0
OC_ERR_INVALID_SIDE5Side is neither buy nor sell
OC_ERR_NULL_ARGUMENT6A required pointer is NULL
OC_ERR_OUT_OF_MEMORY7Allocation failed
OC_ERR_INTERNAL8Unexpected internal error

const char* oc_status_string(oc_status) returns a static description; const char* oc_version(void) returns the library version.

Lifecycle

oc_book*  oc_book_new(void);
void      oc_book_free(oc_book* book);
oc_status oc_book_clear(oc_book* book);

oc_book_new returns NULL if allocation fails. oc_book_free(NULL) is a no-op.

Order entry

oc_status oc_book_limit(oc_book* book, oc_side side, uint64_t order_id,
                        uint32_t quantity, uint64_t price, uint32_t* filled);
oc_status oc_book_market(oc_book* book, oc_side side, uint64_t order_id,
                         uint32_t quantity, uint32_t* filled);

Submit a limit or an immediate-or-cancel market order. filled (optional) receives the quantity filled immediately; it is set to 0 when the call fails.

oc_status oc_book_cancel(oc_book* book, uint64_t order_id);
oc_status oc_book_reduce(oc_book* book, uint64_t order_id, uint32_t quantity);

Cancel a resting order, or reduce its quantity while keeping queue priority (reducing by the full amount cancels it).

Trade callback

oc_status oc_book_set_trade_callback(oc_book* book, oc_trade_callback callback, void* user_data);

Register a function called once per execution, after the operation has updated the book. user_data is passed through unchanged. The callback may query the book but must not modify it; the oc_trade pointer is only valid during the call. Pass NULL to disable.

Building and linking

bazel build //:shared_lib                     # lib_orderly_chaos.so / .dylib / .dll
cc -std=c99 -I include app.c -L bazel-bin -l:lib_orderly_chaos.so -o app   # Linux example

With Bazel, depend on //:orderly_chaos_c to link the C API statically. See examples/c/quickstart.c for a complete program.

Using from other languages

The API uses only fixed-width integers, plain structs, and function pointers, so it maps directly onto any C FFI. For example, Rust:

#[repr(C)] pub struct OcBook { _private: [u8; 0] }

extern "C" {
    fn oc_book_new() -> *mut OcBook;
    fn oc_book_free(book: *mut OcBook);
    fn oc_book_limit(book: *mut OcBook, side: i32, id: u64, qty: u32, price: u64, filled: *mut u32) -> i32;
    fn oc_book_best_price(book: *const OcBook, side: i32) -> u64;
}

The Python package is itself a thin ctypes layer over this API (python/orderly_chaos/_library.py) and is a good reference for writing new bindings.
