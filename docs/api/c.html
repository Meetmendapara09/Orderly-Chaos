C API Reference

The C API provides a language-agnostic interface for integrating Orderly Chaos with other systems. All functions use the extern "C" calling convention.

Header File

#include "lib_lob.hpp"

Types

TypeC TypeDescription
LOB::UIDuint64_tOrder identifier
LOB::SideboolOrder side (true=buy, false=sell)
LOB::Quantityuint32_tNumber of shares
LOB::Priceuint64_tPrice value
LOB::Volumeuint32_tTotal share volume
LOB::Countuint32_tOrder count
LOB::Order*void*Pointer to an order
LOB::LimitOrderBook*void*Pointer to the book

Lifecycle Functions

LOB::LimitOrderBook* new_()
Create a new limit order book and return a pointer to it.
void delete_(LOB::LimitOrderBook* book)
Delete the limit order book instance from memory.
ParameterTypeDescription
bookLimitOrderBook*Pointer to the book to delete
void clear(LOB::LimitOrderBook* book)
Clear all orders from the book.
ParameterTypeDescription
bookLimitOrderBook*Pointer to the book

Limit Order Functions

void limit_sell(LOB::LimitOrderBook* book, LOB::UID uid, LOB::Quantity quantity, LOB::Price price)
Place a sell limit order. Matches against existing buy orders if the price crosses the spread.
void limit_buy(LOB::LimitOrderBook* book, LOB::UID uid, LOB::Quantity quantity, LOB::Price price)
Place a buy limit order. Matches against existing sell orders if the price crosses the spread.
void limit(LOB::LimitOrderBook* book, LOB::Side side, LOB::UID uid, LOB::Quantity quantity, LOB::Price price)
Place a limit order on the specified side.

Order Management

bool has(LOB::LimitOrderBook* book, LOB::UID uid)
Return true if the book contains an order with the given ID.
const LOB::Order* get(LOB::LimitOrderBook* book, LOB::UID uid)
Get a pointer to the order with the given ID.
void cancel(LOB::LimitOrderBook* book, LOB::UID uid)
Cancel an existing order by its ID.

Market Order Functions

void market_sell(LOB::LimitOrderBook* book, LOB::UID uid, LOB::Quantity quantity)
Execute a market sell, matching against buy-side liquidity.
void market_buy(LOB::LimitOrderBook* book, LOB::UID uid, LOB::Quantity quantity)
Execute a market buy, matching against sell-side liquidity.
void market(LOB::LimitOrderBook* book, LOB::Side side, LOB::UID uid, LOB::Quantity quantity)
Execute a market order on the specified side.

Price/Level Functions

LOB::Price best_sell(LOB::LimitOrderBook* book)
Return the best (lowest) sell price. Returns 0 if no sell orders exist.
LOB::Price best_buy(LOB::LimitOrderBook* book)
Return the best (highest) buy price. Returns 0 if no buy orders exist.
LOB::Price best(LOB::LimitOrderBook* book, LOB::Side side)
Return the best price for the given side. side=true for buy, side=false for sell.

Volume Functions

LOB::Volume volume_sell_price(LOB::LimitOrderBook* book, LOB::Price price)
Return the volume at a specific sell-side price.
LOB::Volume volume_sell(LOB::LimitOrderBook* book)
Return the total volume on the sell side.
LOB::Volume volume_buy_price(LOB::LimitOrderBook* book, LOB::Price price)
Return the volume at a specific buy-side price.
LOB::Volume volume_buy(LOB::LimitOrderBook* book)
Return the total volume on the buy side.
LOB::Volume volume_price(LOB::LimitOrderBook* book, LOB::Price price)
Return the total volume at a specific price across both sides.
LOB::Volume volume(LOB::LimitOrderBook* book)
Return the total volume across both sides of the book.

Count Functions

LOB::Count count_at(LOB::LimitOrderBook* book, LOB::Price price)
Return the number of orders at a specific price.
LOB::Count count_sell(LOB::LimitOrderBook* book)
Return the number of orders on the sell side.
LOB::Count count_buy(LOB::LimitOrderBook* book)
Return the number of orders on the buy side.
LOB::Count count(LOB::LimitOrderBook* book)
Return the total number of orders in the book.
