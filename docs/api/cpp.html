C++ API Reference

The native C++ API for Orderly Chaos provides direct access to the high-performance matching engine.

Header Files

#include "limit_order_book.hpp"  // Main LOB class
#include "lib_lob.hpp"           // C-compatible API
#include "limit_tree.hpp"        // Underlying tree structure
#include "structures.hpp"        // Order, Limit, Side types

Namespace

All C++ classes are in the LOB namespace.

LOB::LimitOrderBook

The main order book class implementing a continuous double auction with price-time priority.

LimitOrderBook()
Initialize a new empty limit order book.

Supporting Structures

LOB::Order

Represents a single order in the book.

struct Order {
    UID uid;           // unique order ID
    Side side;         // buy or sell
    Quantity quantity; // number of shares
    Price price;       // price of the order
    Limit* limit;      // pointer to the limit level
};

LOB::Limit

Represents a price level in the order book tree.

struct Limit {
    Price key;             // price level
    Volume volume;         // total volume at this price
    Count count;           // number of orders at this price
    Order* head;           // head of the order queue
    Order* tail;           // tail of the order queue
    Limit* next;           // next price level
    Limit* prev;           // previous price level
};
