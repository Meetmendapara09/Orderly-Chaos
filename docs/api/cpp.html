Query Methods

bool has(UID order_id) const
Check if an order with the given ID exists. O(1) average time.
const Order& get(UID order_id)
Get a reference to the order with the given ID.
Price best_sell() const
Return the best (lowest) sell/ask price. Returns 0 if empty. O(1).
Price best_buy() const
Return the best (highest) buy/bid price. Returns 0 if empty. O(1).
Price best(Side side) const
Return the best price for the given side.
Price price() const
Return the current midpoint price. O(1).
Price last_best_sell() const
Return the last best sell price before the most recent change.
Price last_best_buy() const

Management Methods

void cancel(UID order_id)
Cancel an existing order. O(log n) due to tree removal.
void reduce(UID order_id, Quantity quantity)
Reduce the quantity of an existing order by the specified amount.
void clear()
Remove all orders from both sides of the book. O(n).

Structures

LOB::Order

struct Order {
    UID uid;           // unique order ID
    Side side;         // buy or sell
    Quantity quantity; // shares in this order
    Price price;       // price of the order
    Limit* limit;      // pointer to containing price level
    Order* prev;       // previous order at this price level
    Order* next;       // next order at this price level
};

LOB::Limit

struct Limit {
    Price key;             // price level
    Volume volume;         // total volume at this price
    Count count;           // orders at this price
    Order* head;           // first order (time-priority queue)
    Order* tail;           // last order
    Limit* next;           // next price level
    Limit* prev;           // previous price level
};
