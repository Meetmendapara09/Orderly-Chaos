Setup

#include <orderly_chaos/orderly_chaos.hpp>

int main() {
    orderly_chaos::LimitOrderBook book;
    book.limit(orderly_chaos::Side::Sell, 1, 100, 10'050);
    auto filled = book.limit(orderly_chaos::Side::Buy, 2, 40, 10'050);  // 40
    return filled == 40 ? 0 : 1;
}

Compile with -std=c++17 and the include directories include and third_party/robin_map/include, or depend on the Bazel target //:orderly_chaos. Code written for 0.1 can keep using the namespace alias LOB.

LimitOrderBook

Default constructible, movable, not copyable. Not thread-safe: use one book per thread or synchronise access.

Order entry

Quantity limit(Side side, UID order_id, Quantity quantity, Price price);
Quantity limit_buy(UID order_id, Quantity quantity, Price price);
Quantity limit_sell(UID order_id, Quantity quantity, Price price);

Submit a limit order. Crossing quantity trades at the resting prices; the remainder rests. returns the quantity filled immediately.

throws OrderBookError with DuplicateOrderId, InvalidQuantity (0), or InvalidPrice (0).

Quantity market(Side side, UID order_id, Quantity quantity);
Quantity market_buy(UID order_id, Quantity quantity);
Quantity market_sell(UID order_id, Quantity quantity);

Submit an immediate-or-cancel market order. returns the quantity filled; the remainder is discarded. throws InvalidQuantity for 0.

void cancel(UID order_id);
void reduce(UID order_id, Quantity quantity);
void clear();

cancel removes a resting order. reduce lowers its quantity keeping queue priority (the full amount cancels it). clear removes everything.

throws UnknownOrderId; reduce also throws InvalidQuantity for 0 or more than the open quantity.

Trade handler

using TradeHandler = std::function<void(const Trade&)>;
void set_trade_handler(TradeHandler handler);   // nullptr disables events

Called once per execution after the operation has updated the book. The handler may query the book but must not modify it. If it throws, the remaining trades are still delivered and the first exception is rethrown.

std::vector<orderly_chaos::Trade> trades;
book.set_trade_handler([&](const orderly_chaos::Trade& trade) { trades.push_back(trade); });

Diagnostics

void check_invariants() const;

Verifies every internal invariant in O(N) and throws std::logic_error on the first violation. Intended for tests, fuzzing, and debugging, not for hot paths.

Errors

try {
    book.cancel(42);
} catch (const orderly_chaos::OrderBookError& error) {
    if (error.code() == orderly_chaos::ErrorCode::UnknownOrderId) { /* ... */ }
    std::cerr << error.what() << '\n';   // "unknown order id [OC_ERR_UNKNOWN_ORDER_ID]: no resting order with id 42"
}

OrderBookError derives from std::runtime_error. ErrorCode values are DuplicateOrderId, UnknownOrderId, InvalidQuantity, and InvalidPrice; to_string(code) returns a short description.

Guarantees

  • A call that throws OrderBookError has not modified the book.
  • If memory allocation fails during matching, the book stays consistent: trades already made are kept and the incoming order is dropped.
  • Trades always execute at the maker's price and never through the taker's limit.
  • All cached aggregates match the underlying orders at all times (verified by check_invariants() in the test suite).
