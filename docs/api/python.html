Python API Reference

The Python API for Orderly Chaos provides a high-level interface to the C++ matching engine through ctypes.

Module Overview

All classes are accessible from the orderly_chaos package:

from orderly_chaos import LimitOrderBook

LimitOrderBook

The main class for interacting with the order book engine.

LimitOrderBook()
Initialize a new empty limit order book.

Order Management

limit_sell(order_id: int, quantity: int, price: int) → None
Place a sell limit order in the book. If the order crosses the spread, it will match against existing orders.
ParameterTypeDescription
order_idintUnique identifier for the order
quantityintNumber of shares in the order
priceintLimit price for the order
limit_buy(order_id: int, quantity: int, price: int) → None
Place a buy limit order in the book. If the order crosses the spread, it will match against existing orders.
ParameterTypeDescription
order_idintUnique identifier for the order
quantityintNumber of shares in the order
priceintLimit price for the order
limit(side: bool, order_id: int, quantity: int, price: int) → None
Place a limit order on either side. Use side=True for buy, side=False for sell.
ParameterTypeDescription
sideboolBuy (True) or sell (False)
order_idintUnique identifier for the order
quantityintNumber of shares in the order
priceintLimit price for the order
cancel(order_id: int) → None
Cancel an existing order by its ID.
ParameterTypeDescription
order_idintThe ID of the order to cancel

Market Orders

market_sell(order_id: int, quantity: int) → None
Execute a market sell order, matching against buy-side liquidity.
ParameterTypeDescription
order_idintUnique identifier for the order
quantityintNumber of shares to sell at market
market_buy(order_id: int, quantity: int) → None
Execute a market buy order, matching against sell-side liquidity.
ParameterTypeDescription
order_idintUnique identifier for the order
quantityintNumber of shares to buy at market
market(side: bool, order_id: int, quantity: int) → None
Execute a market order on either side. Use side=True for buy, side=False for sell.

Query Methods

has(order_id: int) → bool
Check if an order with the given ID exists in the book.
best_sell() → int
Return the best (lowest) sell/ask price in the book. Returns 0 if no sell orders exist.
best_buy() → int
Return the best (highest) buy/bid price in the book. Returns 0 if no buy orders exist.
best(side: bool) → int
Return the best price for the given side. side=True for buy, side=False for sell.
volume() → int
Return the total volume of all orders in the book (both sides).
volume(price: int) → int
Return the volume at a specific price level.
volume_sell() → int
Return the total volume on the sell side of the book.
volume_buy() → int
Return the total volume on the buy side of the book.
count() → int
Return the total number of orders in the book.
count_sell() → int
Return the number of orders on the sell side.
count_buy() → int
Return the number of orders on the buy side.
count_at(price: int) → int
Return the number of orders at a specific price level.
clear() → None
Remove all orders from the book, resetting it to an empty state.
