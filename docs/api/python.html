LimitOrderBook

The main class for interacting with the order book. All methods are thread-unsafe; use external synchronization if accessing from multiple threads.

class LimitOrderBook
Initialize a new empty limit order book instance.

Order Placement

limit_sell(order_id: int, quantity: int, price: int) → None
Place a sell limit order at the given price.
ParameterTypeDescription
order_idintUnique identifier for the order
quantityintNumber of shares to sell
priceintLimit price for the order
limit_buy(order_id: int, quantity: int, price: int) → None
Place a buy limit order at the given price.
ParameterTypeDescription
order_idintUnique identifier for the order
quantityintNumber of shares to buy
priceintLimit price for the order
limit(side: bool, order_id: int, quantity: int, price: int) → None
Place a limit order on the specified side. True for buy, False for sell.

Market Orders

market_sell(order_id: int, quantity: int) → None
Execute a market sell order, matching against buy-side liquidity.
market_buy(order_id: int, quantity: int) → None
Execute a market buy order, matching against sell-side liquidity.
market(side: bool, order_id: int, quantity: int) → None
Execute a market order on the specified side. True for buy, False for sell.

Query Methods

has(order_id: int) → bool
Return True if an order with the given ID exists in the book.
best_sell() → int
Return the best (lowest) sell/ask price. Returns 0 if no sell orders exist.
best_buy() → int
Return the best (highest) buy/bid price. Returns 0 if no buy orders exist.
best(side: bool) → int
Return the best price for the given side. True for buy, False for sell.
volume(price: int | None = None) → int
Return the volume at a specific price, or total volume if no price is given.
volume_sell(price: int | None = None) → int
Return the sell-side volume at a specific price, or total sell-side volume.
volume_buy(price: int | None = None) → int
Return the buy-side volume at a specific price, or total buy-side volume.
count() → int
Return the total number of orders in the book.
count_sell() → int
Return the number of orders on the sell side.
count_buy() → int
Return the number of orders on the buy side.
count_at(price: int) → int
Return the number of orders at a specific price level.

Order Management

cancel(order_id: int) → None
Cancel an existing order by its ID.
clear() → None
Remove all orders from the book, resetting it to an empty state.
