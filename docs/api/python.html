Summary

from orderly_chaos import LimitOrderBook, Side, Trade, UnknownOrderIdError

book = LimitOrderBook(on_trade=lambda t: print(t.quantity, "@", t.price))
book.limit(Side.SELL, order_id=1, quantity=100, price=10_050)   # returns 0 (rested)
book.limit(Side.BUY, order_id=2, quantity=40, price=10_050)     # returns 40 (traded)
book.market(Side.BUY, order_id=3, quantity=100)                 # returns 60, rest discarded
try:
    book.cancel(1)                                              # already filled
except UnknownOrderIdError as error:
    print(error)

LimitOrderBook

A price-time priority limit order book. Prices are integer ticks (at least 1), quantities are integers from 1 to 232 - 1, and order IDs are integers from 0 to 264 - 1 that must be unique among resting orders. Arguments outside these ranges raise an exception instead of being silently truncated.

Wherever a side is expected you may pass Side.BUY / Side.SELL, the strings "buy" / "sell" (also "bid" / "ask"), or the legacy booleans True (buy) / False (sell).

Constructor and lifecycle

LimitOrderBook(on_trade: Callable[[Trade], None] | None = None)

Create an empty book. on_trade, if given, receives every trade.

raises LibraryError if the native library cannot be found or is incompatible.

close() -> None
closed: bool                                   # property

Free the native book immediately. Afterwards every method raises OrderlyChaosError. Closing twice is harmless. Books are also freed automatically when garbage collected, and can be used as context managers:

with LimitOrderBook() as book:
    book.limit_buy(1, 10, 100)
assert book.closed

Order entry

limit(side, order_id: int, quantity: int, price: int) -> int
limit_buy(order_id: int, quantity: int, price: int) -> int
limit_sell(order_id: int, quantity: int, price: int) -> int

Submit a limit order. The part that crosses the spread trades immediately at the resting orders' prices; the remainder rests at price.

returns the quantity filled immediately (0 if it simply rested).

raises DuplicateOrderIdError if order_id is resting, InvalidQuantityError for a quantity of 0 or out of range, InvalidPriceError for a price of 0 or out of range, InvalidSideError, TypeError for non-integers.

book.limit_sell(1, 30, 100)
book.limit(Side.BUY, 2, 50, 101)   # returns 30; 20 rest as a bid at 101
market(side, order_id: int, quantity: int) -> int
market_buy(order_id: int, quantity: int) -> int
market_sell(order_id: int, quantity: int) -> int

Submit an immediate-or-cancel market order. It trades against the opposite side best price first; any unfilled remainder is discarded. order_id only labels the trades and does not need to be unique.

returns the quantity filled (0 if the opposite side is empty).

raises InvalidQuantityError, InvalidSideError, TypeError.

cancel(order_id: int) -> None

Remove a resting order.

raises UnknownOrderIdError (a KeyError) if no resting order has this ID, for example because it was already filled.

reduce(order_id: int, quantity: int) -> None

Lower a resting order's quantity by quantity while keeping its place in the queue. Reducing by the full open quantity cancels it.

raises UnknownOrderIdError; InvalidQuantityError if quantity is 0 or larger than the open quantity.

clear() -> None

Remove every order. All IDs become available again.

Order queries

has(order_id: int) -> bool
order_id in book                               # same, never raises
len(book)                                      # number of resting orders

Check whether an order is resting.

get(order_id: int) -> Order

Return an immutable snapshot of a resting order (its current open quantity, side, and price).

raises UnknownOrderIdError.

book.limit_buy(7, 25, 99)
book.get(7)   # Order(order_id=7, side=<Side.BUY: 1>, quantity=25, price=99)

Prices

Price queries return None when there is no price (for example, the best ask of a book with no sell orders).

best(side) -> int | None
best_buy() -> int | None                       # highest bid
best_sell() -> int | None                      # lowest ask

Best price of a side. O(1).

mid_price() -> int | None
spread() -> int | None

mid_price is the midpoint of the best bid and ask rounded down, the only best price if one side is empty, or None for an empty book. spread is best ask minus best bid, or None unless both sides have orders.

Volumes and counts

volume(price: int | None = None) -> int
volume_buy(price: int | None = None) -> int
volume_sell(price: int | None = None) -> int
best_volume(side) -> int

Open (unfilled) quantity: in the whole book, on one side, or at one price when price is given. best_volume is the quantity at the best price of a side. All are O(1).

count() -> int
count_buy() -> int
count_sell() -> int
count_at(price: int) -> int

Number of resting orders in total, per side, or at a price.

Depth

depth(side, levels: int = 10) -> list[PriceLevel]

Up to levels aggregated price levels of a side, best price first: a "level 2" market-depth snapshot.

for level in book.depth(Side.BUY, levels=5):
    print(f"{level.price:>8} {level.volume:>8} ({level.count} orders)")

Trade events

on_trade: Callable[[Trade], None] | None      # read/write property

The function called once per execution, in order, after the operation has fully updated the book. The handler may query the book but must not modify it. If the handler raises, the remaining trades are still delivered and the first exception is re-raised from the call that produced the trades. Set to None to stop events. 

fills = []
book.on_trade = fills.append
book.limit_sell(1, 10, 100)
book.market_buy(2, 4)
fills[0]   # Trade(taker_id=2, maker_id=1, taker_side=<Side.BUY: 1>, price=100, quantity=4, maker_remaining=6)

Types

class Side(enum.IntEnum): SELL = 0; BUY = 1

Side.BUY.opposite returns Side.SELL. Side.parse(value) converts any accepted side value or raises InvalidSideError.

@dataclass(frozen=True)
class Order: order_id: int; side: Side; quantity: int; price: int

Snapshot returned by get(). quantity is the open quantity.

@dataclass(frozen=True)
class Trade: taker_id: int; maker_id: int; taker_side: Side; price: int; quantity: int; maker_remaining: int

One execution. price is the maker's price; maker_remaining is 0 when the maker was fully filled.

@dataclass(frozen=True)
class PriceLevel: price: int; volume: int; count: int

One aggregated price level from depth().

Exceptions

OrderlyChaosError
    LibraryError                      (also OSError)
    OrderBookError                    .status holds the C status code
        DuplicateOrderIdError         (also ValueError)
        UnknownOrderIdError           (also KeyError)
        InvalidQuantityError          (also ValueError)
        InvalidPriceError             (also ValueError)
        InvalidSideError              (also ValueError)

A rejected operation never changes the book. Non-integer arguments raise TypeError; an out-of-range order_id raises ValueError. Every OrderBookError carries .status (the numeric C status) and .code_name (for example "OC_ERR_UNKNOWN_ORDER_ID"), and its message combines the failed operation with the reason, so errors can be traced across the Python, C, and C++ references. See the overview for what causes each error and how to fix it.

Library loading

Importing the package never loads native code; the library is loaded when the first LimitOrderBook is created. The package looks for lib_orderly_chaos*.so (Linux), .dylib/.so (macOS), or .dll/.pyd (Windows) next to its own files. Set the ORDERLY_CHAOS_LIBRARY environment variable to load a specific file instead. The library's version must match the package's major and minor version.

Calls are made with the GIL held, so a book may be shared between threads without memory corruption. Each call is atomic; sequences of calls are not, so use your own lock when you need, for example, "check then cancel" to be atomic.
