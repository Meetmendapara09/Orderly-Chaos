Quick start (Python)

from orderly_chaos import LimitOrderBook, Side, UnknownOrderIdError

book = LimitOrderBook(on_trade=lambda t: print(f"TRADE taker={t.taker_id} maker={t.maker_id} qty={t.quantity} @ {t.price}"))

book.limit(Side.SELL, order_id=1, quantity=100, price=10_050)  # ask 100 @ 100.50
book.limit(Side.SELL, order_id=2, quantity=200, price=10_075)  # ask 200 @ 100.75
book.limit(Side.BUY, order_id=3, quantity=150, price=10_000)   # bid 150 @ 100.00

filled = book.limit(Side.BUY, order_id=4, quantity=250, price=10_050)
print(f"order 4 filled {filled}, resting {book.get(4).quantity}")
print(f"market buy filled {book.market(Side.BUY, order_id=5, quantity=500)} of 500")

try:
    book.cancel(999)
except UnknownOrderIdError as error:
    print(f"rejected: {error}")

Replaying order events

When to use: you have a sequence of order events (from an exchange's order-by-order feed, or produced by a strategy) and want to reconstruct the book, observe trades, and measure prices. The example reads action,order_id,side,quantity,price rows, applies them in order, logs rejected events without stopping, and reports the volume-weighted average trade price. 

def replay(rows):
    trades = []
    book = LimitOrderBook(on_trade=trades.append)
    for row in rows:
        try:
            if row["action"] == "limit":
                book.limit(row["side"], int(row["order_id"]), int(row["quantity"]), int(row["price"]))
            elif row["action"] == "market":
                book.market(row["side"], int(row["order_id"]), int(row["quantity"]))
            elif row["action"] == "cancel":
                book.cancel(int(row["order_id"]))
            elif row["action"] == "reduce":
                book.reduce(int(row["order_id"]), int(row["quantity"]))
        except OrderBookError as error:
            print("rejected:", error)   # the book is unchanged; keep going
    return trades

Market maker simulation

When to use: research and teaching. A market maker keeps one bid and one ask around the mid price, re-quotes whenever a quote is filled, leans its quotes against its inventory, and tracks cash and profit and loss from the trade events, while random traders send market and limit orders. It shows how to tell your own fills apart from other participants' trades with the maker_id field. 

def on_trade(trade):
    side = maker_orders.get(trade.maker_id)   # was one of our quotes hit?
    if side is Side.BUY:
        position["inventory"] += trade.quantity
        position["cash"] -= trade.quantity * trade.price
    elif side is Side.SELL:
        position["inventory"] -= trade.quantity
        position["cash"] += trade.quantity * trade.price

C++ quick start

#include <iostream>
#include <orderly_chaos/orderly_chaos.hpp>

using namespace orderly_chaos;

int main() {
    LimitOrderBook book;
    book.set_trade_handler([](const Trade& t) {
        std::cout << "TRADE " << t.quantity << " @ " << t.price << '\n';
    });
    book.limit(Side::Sell, 1, 100, 10'050);
    book.limit(Side::Buy, 2, 150, 10'000);
    const auto filled = book.limit(Side::Buy, 3, 250, 10'050);   // 100
    for (const auto& level : book.depth(Side::Buy, 5))
        std::cout << level.price << " x " << level.volume << '\n';
    try {
        book.cancel(999);
    } catch (const OrderBookError& error) {
        std::cout << "rejected: " << error.what() << '\n';
    }
    return filled == 100 ? 0 : 1;
}

Common patterns

Cancel an order that may already be filled

try:
    book.cancel(order_id)
except UnknownOrderIdError:
    pass   # it was filled (or cancelled) already

Cancel and replace (amend price)

if order_id in book:
    book.cancel(order_id)
book.limit(side, new_order_id, quantity, new_price)   # a new price always loses queue priority

Top-of-book snapshot

snapshot = {
    "bid": book.best_buy(), "bid_size": book.best_volume(Side.BUY),
    "ask": book.best_sell(), "ask_size": book.best_volume(Side.SELL),
    "mid": book.mid_price(), "spread": book.spread(),
}

Generating order IDs

from itertools import count
next_id = count(1).__next__
book.limit(Side.BUY, next_id(), 10, 100)
