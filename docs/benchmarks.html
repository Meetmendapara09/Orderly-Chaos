Performance Benchmarks

Orderly Chaos is optimized for high-throughput, low-latency order matching. Below are benchmark results from our C++ benchmark suite.

How to Run Benchmarks

scons benchmark

This compiles and runs the benchmark binary located at benchmark/benchmark_lob.cpp.

Benchmark Methodology

Benchmarks measure the time to insert, match, and cancel orders under various conditions. All tests use -O2 -march=native -pipe -pedantic -Wall compiler flags.

Memory Efficiency

The order book uses a memory pool pattern:

  • Price levels stored in a red-black tree (O(n) memory for n levels)
  • Orders at each level stored in a doubly-linked list (O(1) insertion)
  • Order lookup uses a hash map for O(1) access by ID
  • No memory allocations during matching (pre-allocated)
