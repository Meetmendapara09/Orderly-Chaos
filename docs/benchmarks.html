Performance Benchmarks

Orderly Chaos delivers sub-microsecond latencies with O(log n) operations for all critical paths through the matching engine.

Benchmarking Methodology

Run the benchmark suite with:

scons benchmark

All benchmarks use -O2 -march=native -pipe -pedantic -Wall compiler flags and run on the production C++ environment.

Memory Efficiency

The order book uses a memory-efficient design:

  • Tree nodes: One node per price level, ~64 bytes each
  • Order nodes: One node per order, ~40 bytes each
  • Hash map: O(n) for n orders (amortized)
  • Aggregates: O(1) extra space per tree (best pointer, volume, count)
  • No allocations during matching: Pre-allocated pool pattern
