Quick Start

Install

pip install orderly-chaos

Python Usage

from orderly_chaos import LimitOrderBook

book = LimitOrderBook()
book.limit_sell(order_id=1, quantity=100, price=102.50)
book.limit_buy(order_id=2, quantity=50, price=102.40)
print(book.volume())  # 150

C++ Usage

#include "limit_order_book.hpp"

LOB::LimitOrderBook book;
book.limit_sell(1, 100, 10250);
book.limit_buy(2, 50, 10240);
std::cout << book.volume();
