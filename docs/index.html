Design

Specified, tested, and measured

Every behaviour is specified in the overview, validated at the API boundary, and checked against an independent reference model on every build.

Predictable performance

A balanced tree of price levels guarantees O(log n) level changes, cached top of book answers best price and volume in O(1), and FIFO queues make joining a level O(1).

Architecture

Exchange-grade semantics

Strict price-time priority, trades at the resting price, immediate-or-cancel market orders, priority-preserving reduces, and trade events for every execution.

Matching rules

Safe by default

Duplicate IDs, zero quantities, zero prices, and unknown orders are rejected without touching the book. No exception ever crosses the C boundary.

Error handling

Three APIs, one engine

Include a C++ header, link the C API from any language with an FFI, or pip install the typed Python package. All three share the same tested core.

API reference
In five lines

Submit orders, get trades

from orderly_chaos import LimitOrderBook, Side

book = LimitOrderBook(on_trade=print)
book.limit(Side.SELL, order_id=1, quantity=100, price=10_050)   # rests: 0 filled
book.limit(Side.BUY, order_id=2, quantity=40, price=10_050)     # trades: 40 filled
print(book.best_sell(), book.volume_sell())                     # 10050 60
