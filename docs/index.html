Features

Built for Speed and Precision

High-Performance Core

Written in optimized C++ with O(log n) operations for all critical paths. Red-black trees for price levels, hash maps for O(1) order lookup. Compiled with -O2 -march=native -pipe.

● O(log n) inserts ● O(1) lookups ● ~0.3μs per op
🐍

Python Bindings

Seamless integration via ctypes. Rapid prototyping for research and trading strategies.
⚙️

C++ Native

Direct access to the engine for maximum performance. Zero abstraction overhead.

Market Data Ready

Built for reception of market data streams with price-time priority matching. Handles limit, market, cancel, and reduce operations with precision.
